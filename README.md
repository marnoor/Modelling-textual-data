# Modelling-textual-data

This project is for exploring and modelling of some of the letters related to the Easter Rising Ireland, 1916.

L_001: Letter from James Joseph Walsh to John Quinn, 29 June 1923
L_002: Letter from Alice Stopford Green to John Quinn, 27 August 1916
L_003: Letter from Richard W. Hale to John Quinn, 18 August 1916

- CSV / Dataset of letters and persons
- Facsimiles of L_001, L_002, L_003
- TEI version of L_001
- Link to analyse lexical patterns with Voyant
- Annotate entities with Recogito
- Locations mentioned / GeoJSON with Recogito
